# fetal-distress-cardiotocography-neural-analytics
End-to-end fetal distress prediction using FHR and uterine contraction (UC) signals. Includes data loading, exploratory data analysis, preprocessing, feature engineering, model training, and evaluation. Uses the CTU-CHB Intrapartum Cardiotocography Database (PhysioNet) and a hybrid 1D CNN-LSTM model built with PyTorch for binary classification.
