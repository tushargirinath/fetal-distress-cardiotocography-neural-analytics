## Overview

A deep learning system for detecting fetal distress during labour using Cardiotocography (CTG) signals. The model analyses Fetal Heart Rate (FHR) and Uterine Contraction (UC) patterns to predict whether a baby is compromised, providing an early warning to clinicians.

**Dataset**: [CTU-CHB Intrapartum Cardiotocography Database](https://physionet.org/content/ctu-uhb-ctgdb/1.0.0/) — 552 labour recordings with birth outcomes.

**Approach**: 1D CNN-LSTM hybrid model trained on the last 20 minutes of CTG signals before delivery.

## Quick Start

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

### 2. Run the full pipeline (training + evaluation)

Open and run `workflow.ipynb` from start to finish:

```bash
jupyter notebook workflow.ipynb
```

The notebook will:
- Load all 552 raw recordings from `data/raw/`
- Parse clinical outcomes and define distress labels (pH < 7.15)
- Preprocess signals (handle missing data, clip, normalise)
- Split into train/val/test sets (70/15/15, stratified)
- Train the CNN-LSTM model with early stopping
- Evaluate on the held-out test set
- Save all artifacts (model weights, scaler stats, predictions, plots)

### 3. Run inference on new recordings

Once the model is trained (or using pre-trained weights from `artifacts/`):

```bash
# Single recording
python generate_outcomes.py --input data/raw/1001.hea

# All recordings in a directory
python generate_outcomes.py --input data/raw/

# Custom output path
python generate_outcomes.py --input data/raw/ --output my_predictions.csv
```

**Input**: WFDB-format CTG recordings (`.hea` + `.dat` files). Each recording has 2 channels (FHR, UC) sampled at 4 Hz.

**Output**: A CSV with columns:
- `record_id`: recording identifier
- `distress_prob`: model's estimated probability of fetal distress (0.0–1.0)
- `prediction`: binary label (1 = distressed, 0 = normal, threshold = 0.5)

## Methodology Summary

**Target definition**: Fetal distress = umbilical cord pH < 7.15 (fallback: 5-min Apgar < 7). This threshold captures clinically meaningful acidosis while providing enough positive samples for training.

**Signal processing**: Missing FHR values (sensor dropout, coded as 0) are interpolated. Signals are clipped to physiological ranges and Z-normalised. The last 20 minutes before delivery are used — the period most relevant to delivery outcomes.

**Model**: A 1D CNN-LSTM architecture. Three CNN blocks extract local temporal patterns (decelerations, accelerations). A bidirectional LSTM captures longer-range context (how the heart rate evolves over time). A fully-connected head outputs a distress probability.

**Class imbalance handling**: Weighted random sampling during training + class-weighted BCE loss.

**Evaluation metrics**: AUC-ROC, AUC-PR, F1, sensitivity/specificity at various thresholds, and Matthews Correlation Coefficient. AUC-PR is particularly important given the class imbalance.

## Key Limitations

- **Small dataset**: 552 recordings limits what the model can learn.
- **Fixed window**: Using only the last 20 minutes discards earlier context.
- **No clinical features**: Gestational age, parity, and other risk factors are not used.
- **Retrospective only**: The model sees the trace up to delivery; a real-time system would need a sliding-window approach.
- **Single dataset**: No external validation on data from other hospitals.
